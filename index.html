How This Rule-Based Checker Works

@

'@' Symbol Confusion

In standard URLs, text before the @ symbol is treated as user credentials. Phishers use this to fake a trusted brand name while directing visitors to a malicious host.

🌐

Raw IP Addresses

Legitimate organizations use registered domain names. Attackers often host phishing pages directly on raw IP addresses (e.g. 192.168.1.1) to bypass domain registration checks.

🔓

Missing HTTPS

Plain http:// lacks TLS encryption. Trustworthy login portals and financial services strictly enforce https:// to protect submitted data.

📏

Unusually Long URLs

Phishing URLs frequently exceed 75 characters, packing excessive parameters, padding, and layered subdomains to conceal fraudulent destinations.
